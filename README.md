<div align="center">

## 📖 **How To Use**

</div>

<br/>

<div align="center">

### 🔗 **Pair Code Method**

</div>

1. Open the website
2. Click **Pair Code** tab
3. Enter WhatsApp number **with country code** (no `+`)
4. Click **Generate Pair Code**
5. Copy the 8-digit code
6. Open WhatsApp → **Settings** → **Linked Devices**
7. Tap **Link with phone number** → enter the code
8. **Copy your Session ID** (`DEVIL~...`)

<br/>

<div align="center">

### 🔳 **QR Code Method**

</div>

1. Open the website
2. Click **QR Code** tab
3. Click **Generate QR Code**
4. Open WhatsApp → **Linked Devices** → **Link a Device**
5. Scan the QR with your phone
6. **Copy your Session ID**

<br/>

### 🤖 **Using Session ID**

Paste the session ID into your bot's config:

```env
SESSION_ID=DEVIL~eyJub2lzZUtleSI6...
```

Start your bot — **DONE!** 🎉
